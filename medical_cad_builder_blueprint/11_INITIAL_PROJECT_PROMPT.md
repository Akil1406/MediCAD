# Initial Full-Stack Coding Prompt

Build a full-stack application named `medical-cad-builder`.

It is a parametric CAD prototyping assistant for medical-tool concepts such as tubes, catheters, connectors, and injector components.

## Required Architecture

```text
React + TypeScript
        ↓
FastAPI REST API
        ↓
LangChain + LangGraph
        ↓
Deterministic Python services
        ↓
CadQuery / Materials / Validation / Simulation
        ↓
SQLite initially
```

## Frontend

Use:
- React

- Vite

## First Milestone

Build a working tube/catheter system before complex autonomous agent behavior.

Catheter parameters:

```text
length_mm
outer_diameter_mm
inner_diameter_mm
tip_length_mm
tip_angle_deg
tolerance_mm
```

## Required FastAPI Endpoints

```text
GET    /health
POST   /api/v1/designs
GET    /api/v1/designs/{design_id}
PATCH  /api/v1/designs/{design_id}/parameters
POST   /api/v1/designs/{design_id}/generate-cad
GET    /api/v1/designs/{design_id}/validation
GET    /api/v1/designs/{design_id}/materials
GET    /api/v1/exports/{export_id}
```

## Rules

React must never directly access:
- CadQuery
- database
- LLM API key
- server filesystem
- simulation software

Everything goes through FastAPI.

Never execute arbitrary Python/CAD code generated by the LLM.

## Initial Flow

```text
React
  ↓
FastAPI
  ↓
Pydantic
  ↓
Deterministic CAD
  ↓
STEP/STL
  ↓
FastAPI
  ↓
React 3D preview
```

Then add:

```text
LangChain
  ↓
LangGraph
  ↓
structured requirement extraction
  ↓
tool calls
  ↓
bounded revision loop
```

Do not claim clinical safety, biocompatibility, regulatory approval, sterility, or patient readiness.
